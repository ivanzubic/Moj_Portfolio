## 🛠️ Korištene tehnologije

- **HTML5** – struktura web stranice
- **CSS3** – dizajn i stilizacija
- **JavaScript** – interaktivnost i funkcionalnosti

## ✨ Funkcionalnosti

- Osobna početna stranica
- Predstavljanje i informacije o meni
- Prikaz projekata
- Kontakt sekcija
- Interaktivni gumbi pomoću JavaScripta
- Responzivan dizajn

## 🚀 Pokretanje projekta

Za lokalno pokretanje projekta:

1. Preuzmi ili kloniraj repozitorij.
2. Otvori mapu projekta u Visual Studio Codeu.
3. Pokreni datoteku `index.html` pomoću Live Server ekstenzije.

